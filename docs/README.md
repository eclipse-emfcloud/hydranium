# Hydranium documentation

Two paths, depending on what you are doing:

- [**Adopting Hydranium**](ADOPTING.md): you are building a modeling language
  on Hydranium. Getting started, the examples, guides and reference.
- [**Contributing to Hydranium**](CONTRIBUTING.md): you are working on
  Hydranium itself. Setup, conventions, testing, releasing, and how the
  framework is built.
